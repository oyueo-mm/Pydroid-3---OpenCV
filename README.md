# OpenCV for Pydroid 3
Pydroid 3 환경에서 **OpenCV를 활용한 컴퓨터 비전 프로젝트 및 실습 코드**를 정리한 저장소입니다.

PC 환경이 아닌 Android 환경에서도 OpenCV를 사용해 볼 수 있도록 프로젝트를 구성했으며, 이미지 처리와 컴퓨터 비전의 기본적인 기능들을 직접 구현하고 실험하는 것을 목적으로 합니다.

## 프로젝트 목적
* Pydroid 3에서 OpenCV를 사용하는 방법 익히기
* OpenCV의 주요 이미지 처리 기능 실습
* 컴퓨터 비전 알고리즘의 동작 원리 이해
* 다양한 OpenCV 프로젝트를 Android 환경에서 실행
* 실습 과정에서 작성한 코드를 체계적으로 정리

## 개발 환경
* Platform: Android
* IDE: Pydroid 3
* Python: 3.13.13
* OpenCV: 4.13.0
* NumPy: 2.4.4

## 참고
이 저장소의 코드는 개인적인 학습 및 실습 목적으로 작성되었습니다.

프로젝트를 진행하면서 코드가 개선되거나 새로운 기능이 추가될 수 있습니다.
